# mtrtk Phase 7: ROS 2 Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the rover's live solution into ROS 2 (Humble and Jazzy) — `NavSatFix`, velocity, time reference, RTK status, camera time marks, IMU/heading when an INS driver provides attitude — from a small `rclpy` node that consumes the daemon's WebSocket, packaged with its own Dockerfiles and a Compose profile, so a Jetson/autonomous-car stack can use mtrtk without the core daemon depending on ROS.

**Architecture:** Two ROS packages under `ros2/`: `mtrtk_msgs` (ament_cmake, custom messages `RtkStatus`, `TimeMark`) and `mtrtk_bridge` (ament_python). The bridge runs the Phase 3 WebSocket protocol in a background asyncio thread (`websockets` library), converts each `epoch`/`update` message with pure-Python functions in `convert.py` (unit-tested in the main repo without ROS), and publishes on `/mtrtk/*` topics from the rclpy node. Optionally it republishes the daemon's NMEA TCP stream as `nmea_msgs/Sentence`. Distribution: `ros2/Dockerfile.humble` and `Dockerfile.jazzy` built from `ros:<distro>-ros-base`, Compose profile `ros2` with host networking.

**Tech Stack:** ROS 2 Humble (Ubuntu 22.04) and Jazzy (Ubuntu 24.04), rclpy, ament_cmake/ament_python, `websockets`, sensor_msgs / geometry_msgs / nmea_msgs, Docker.

**Spec:** `docs/superpowers/specs/2026-09-18-mtrtk-design.md` — *ros2*, *Phase 7*. Prerequisites: Phase 3 (WebSocket protocol) and Phase 6 (`rtk`, `time_marks`, `attitude` in state; NMEA TCP output).

## Global Constraints

- The core daemon never imports ROS; the bridge never imports `mtrtk`. The contract between them is the WebSocket JSON (`snapshot`, `epoch` with `pvt`/`rtk`, `update` with `rtk`/`state.time_mark`) and, optionally, the NMEA TCP stream.
- Topics (namespace `/mtrtk`, configurable): `fix` (`sensor_msgs/NavSatFix`), `vel` (`geometry_msgs/TwistWithCovarianceStamped`, ENU: x east, y north, z up), `time_reference` (`sensor_msgs/TimeReference`), `rtk_status` (`mtrtk_msgs/RtkStatus`), `time_mark` (`mtrtk_msgs/TimeMark`), `imu` (`sensor_msgs/Imu`, orientation only, when attitude exists), `heading` (`std_msgs/Float64`, degrees true, when attitude exists), `nmea` (`nmea_msgs/Sentence`, when `nmea_tcp` is set).
- `NavSatFix.status.status`: `-1` no fix, `0` GNSS fix, `1` DGNSS (`diff_soln` without carrier), `2` RTK float or fixed (GBAS_FIX slot is the conventional RTK indicator); `status.service` bitmask GPS|GLONASS|COMPASS|GALILEO = 15; `position_covariance` diagonal `[hAcc²/2, hAcc²/2, vAcc²]`, `position_covariance_type = 2` (DIAGONAL_KNOWN); `header.stamp` = receiver UTC of the epoch (falls back to node clock when missing); `header.frame_id` param (default `gnss`).
- Params (all with defaults): `ws_url` (`ws://127.0.0.1:8080/ws`), `token` (``), `frame_id` (`gnss`), `namespace` (`/mtrtk`), `nmea_tcp` (`` → off, e.g. `127.0.0.1:10110`), `reconnect_s` (2.0), `stale_s` (5.0; a `fix` with `status=-1` is published once per second while no epoch arrives so consumers see the loss).
- Compose profile `ros2`: service `mtrtk-ros2`, `network_mode: host`, `ROS_DOMAIN_ID` from `.env` (default 0), image tag selectable via `ROS_DISTRO=humble|jazzy` build arg.

```python
"""Pure conversions from mtrtk WebSocket JSON to ROS message field values. No rclpy here (unit-testable anywhere)."""

from __future__ import annotations

import math
from datetime import datetime
from typing import Any

NAN = float("nan")
SERVICE_ALL = 1 | 2 | 4 | 8  # GPS | GLONASS | COMPASS | GALILEO


def stamp_from_iso(iso: str | None) -> tuple[int, int] | None:
    if not iso:
        return None
    dt = datetime.fromisoformat(iso)
    total_ns = int(dt.timestamp()) * 1_000_000_000 + dt.microsecond * 1000
    return total_ns // 1_000_000_000, total_ns % 1_000_000_000


def navsat_status(fix: dict[str, Any]) -> int:
    if fix.get("fix_type", 0) < 2:
        return -1
    if fix.get("carr_soln", 0) >= 1:
        return 2
    return 1 if fix.get("diff_soln") else 0


def _f(value: Any) -> float:
    return NAN if value is None else float(value)


def navsat_fix_fields(pvt: dict[str, Any]) -> dict[str, Any]:
    p, a, f = pvt["position"], pvt["accuracy"], pvt["fix"]
    h = _f(a.get("h_acc_m"))
    v = _f(a.get("v_acc_m"))
    cov = [0.0] * 9
    cov[0] = cov[4] = h * h / 2 if not math.isnan(h) else 0.0
    cov[8] = v * v if not math.isnan(v) else 0.0
    return {
        "latitude": _f(p.get("lat")), "longitude": _f(p.get("lon")), "altitude": _f(p.get("height_m")),
        "status": navsat_status(f), "service": SERVICE_ALL,
        "position_covariance": cov, "position_covariance_type": 2 if not math.isnan(h) else 0,
        "stamp": stamp_from_iso(pvt.get("time", {}).get("utc")),
    }


def twist_fields(pvt: dict[str, Any]) -> dict[str, Any]:
    v, a = pvt["velocity"], pvt["accuracy"]
    s = _f(a.get("s_acc_mps"))
    cov = [0.0] * 36
    if not math.isnan(s):
        cov[0] = cov[7] = cov[14] = s * s
    return {"linear_x": _f(v.get("vel_e_mps")), "linear_y": _f(v.get("vel_n_mps")), "linear_z": -_f(v.get("vel_d_mps")) if v.get("vel_d_mps") is not None else NAN, "covariance": cov, "stamp": stamp_from_iso(pvt.get("time", {}).get("utc"))}


def rtk_status_fields(pvt: dict[str, Any], rtk: dict[str, Any], ntrip_connected: bool) -> dict[str, Any]:
    f, a, d = pvt["fix"], pvt["accuracy"], pvt.get("dops", {})
    return {
        "carr_soln": int(rtk.get("carr_soln") or 0), "fix_type": int(f.get("fix_type", 0)), "diff_soln": bool(f.get("diff_soln")), "num_sv": int(f.get("num_sv", 0)),
        "h_acc": _f(a.get("h_acc_m")), "v_acc": _f(a.get("v_acc_m")), "pdop": _f(d.get("p")), "hdop": _f(d.get("h")),
        "corr_age": _f(rtk.get("corr_age_s")), "corr_age_receiver": _f(rtk.get("corr_age_receiver_s")),
        "baseline": _f(rtk.get("baseline_m")), "rel_pos_n": _f(rtk.get("rel_pos_n_m")), "rel_pos_e": _f(rtk.get("rel_pos_e_m")), "rel_pos_d": _f(rtk.get("rel_pos_d_m")),
        "heading_to_base": _f(rtk.get("heading_deg")) if rtk.get("heading_valid") else NAN,
        "ref_station_id": int(rtk.get("ref_station_id") or 0), "rtcm_rx_total": int(rtk.get("rtcm_rx_total") or 0), "rtcm_crc_failed": int(rtk.get("rtcm_crc_failed") or 0),
        "ntrip_connected": bool(ntrip_connected), "stamp": stamp_from_iso(pvt.get("time", {}).get("utc")),
    }


def time_mark_fields(mark: dict[str, Any]) -> dict[str, Any]:
    stamp = stamp_from_iso(mark.get("rising_utc"))
    return {"channel": int(mark.get("channel", 0)), "count": int(mark.get("count", 0)), "gps_week": int(mark.get("rising_week") or 0), "gps_tow": _f(mark.get("rising_tow_s")), "time_valid": stamp is not None, "acc_est_ns": int(mark.get("acc_est_ns") or 0), "stamp": stamp}


def _quat_from_euler(roll: float, pitch: float, yaw: float) -> tuple[float, float, float, float]:
    cr, sr = math.cos(roll / 2), math.sin(roll / 2)
    cp, sp = math.cos(pitch / 2), math.sin(pitch / 2)
    cy, sy = math.cos(yaw / 2), math.sin(yaw / 2)
    return (round(sr * cp * cy - cr * sp * sy, 12), round(cr * sp * cy + sr * cp * sy, 12), round(cr * cp * sy - sr * sp * cy, 12), round(cr * cp * cy + sr * sp * sy, 12))


def imu_fields(att: dict[str, Any]) -> dict[str, Any]:
    heading = _f(att.get("heading_deg"))
    yaw = math.radians(90.0 - heading) if not math.isnan(heading) else 0.0  # true heading (clockwise from north) -> ENU yaw (ccw from east)
    roll = math.radians(_f(att.get("roll_deg"))) if att.get("roll_deg") is not None else 0.0
    pitch = math.radians(_f(att.get("pitch_deg"))) if att.get("pitch_deg") is not None else 0.0
    cov = [0.0] * 9
    for i, key in enumerate(("acc_roll_deg", "acc_pitch_deg", "acc_heading_deg")):
        v = att.get(key)
        cov[i * 4] = math.radians(float(v)) ** 2 if v is not None else -1.0
    return {"orientation": _quat_from_euler(roll, pitch, yaw), "orientation_covariance": cov}


class EpochAccumulator:
    """Keeps the newest pvt/rtk/attitude from snapshot, epoch and update messages."""

    def __init__(self) -> None:
        self.pvt: dict[str, Any] | None = None
        self.rtk: dict[str, Any] = {}
        self.attitude: dict[str, Any] | None = None
        self.ntrip_connected = False
        self.epochs = 0
        self._marks: list[dict[str, Any]] = []

    def ingest(self, msg: dict[str, Any]) -> bool:
        """Returns True when a new epoch arrived (time to publish fix/vel/rtk)."""
        kind = msg.get("type")
        if kind == "snapshot":
            state = msg["state"]
            self.pvt = {k: state.get(k, {}) for k in ("position", "accuracy", "fix", "velocity", "time", "dops")}
            self.rtk = state.get("rtk") or {}
            self.attitude = state.get("attitude")
            return False
        if kind == "epoch":
            if msg.get("pvt"):
                self.pvt = msg["pvt"]
            if msg.get("rtk") is not None:
                self.rtk = msg["rtk"]
            self.epochs += 1
            return self.pvt is not None
        if kind == "update" and msg.get("topic") == "rtk":
            if msg.get("source") == "ntrip_client.status":
                self.ntrip_connected = bool(msg["data"].get("connected"))
            elif msg.get("source") == "state.time_mark":
                self._marks.append(msg["data"])
        return False

    def pop_time_marks(self) -> list[dict[str, Any]]:
        marks, self._marks = self._marks, []
        return marks
```

- [ ] **Step 2: Write `ros2/mtrtk_bridge/mtrtk_bridge/node.py`**

```python
"""rclpy node: mtrtk WebSocket -> /mtrtk/* topics."""

from __future__ import annotations

import asyncio
import json
import math
import socket
import threading
import time
from typing import Any

import rclpy
from builtin_interfaces.msg import Time
from geometry_msgs.msg import TwistWithCovarianceStamped
from nmea_msgs.msg import Sentence
from rclpy.node import Node
from sensor_msgs.msg import Imu, NavSatFix, NavSatStatus, TimeReference
from std_msgs.msg import Float64

from mtrtk_bridge.convert import EpochAccumulator, imu_fields, navsat_fix_fields, rtk_status_fields, time_mark_fields, twist_fields
from mtrtk_msgs.msg import RtkStatus, TimeMark


class MtrtkBridge(Node):
    def __init__(self) -> None:
        super().__init__("mtrtk_bridge")
        self.declare_parameter("ws_url", "ws://127.0.0.1:8080/ws")
        self.declare_parameter("token", "")
        self.declare_parameter("frame_id", "gnss")
        self.declare_parameter("namespace", "/mtrtk")
        self.declare_parameter("nmea_tcp", "")
        self.declare_parameter("reconnect_s", 2.0)
        self.declare_parameter("stale_s", 5.0)
        ns = self.get_parameter("namespace").value.rstrip("/")
        self.frame_id = self.get_parameter("frame_id").value
        self.pub_fix = self.create_publisher(NavSatFix, f"{ns}/fix", 10)
        self.pub_vel = self.create_publisher(TwistWithCovarianceStamped, f"{ns}/vel", 10)
        self.pub_time = self.create_publisher(TimeReference, f"{ns}/time_reference", 10)
        self.pub_rtk = self.create_publisher(RtkStatus, f"{ns}/rtk_status", 10)
        self.pub_mark = self.create_publisher(TimeMark, f"{ns}/time_mark", 50)
        self.pub_imu = self.create_publisher(Imu, f"{ns}/imu", 10)
        self.pub_heading = self.create_publisher(Float64, f"{ns}/heading", 10)
        self.pub_nmea = self.create_publisher(Sentence, f"{ns}/nmea", 50)
        self.acc = EpochAccumulator()
        self._last_epoch = 0.0
        self._lock = threading.Lock()
        self._stop = threading.Event()
        threading.Thread(target=self._ws_thread, name="mtrtk-ws", daemon=True).start()
        if self.get_parameter("nmea_tcp").value:
            threading.Thread(target=self._nmea_thread, name="mtrtk-nmea", daemon=True).start()
        self.create_timer(1.0, self._watchdog)

    # ------------------------------------------------------------- helpers
    def _stamp(self, stamp: tuple[int, int] | None) -> Time:
        if stamp is None:
            return self.get_clock().now().to_msg()
        return Time(sec=stamp[0], nanosec=stamp[1])

    def _publish_epoch(self) -> None:
        acc = self.acc
        if acc.pvt is None:
            return
        fix = navsat_fix_fields(acc.pvt)
        msg = NavSatFix()
        msg.header.stamp = self._stamp(fix["stamp"])
        msg.header.frame_id = self.frame_id
        msg.status = NavSatStatus(status=fix["status"], service=fix["service"])
        msg.latitude, msg.longitude, msg.altitude = fix["latitude"], fix["longitude"], fix["altitude"]
        msg.position_covariance = fix["position_covariance"]
        msg.position_covariance_type = fix["position_covariance_type"]
        self.pub_fix.publish(msg)

        tw = twist_fields(acc.pvt)
        vel = TwistWithCovarianceStamped()
        vel.header = msg.header
        vel.twist.twist.linear.x, vel.twist.twist.linear.y, vel.twist.twist.linear.z = (0.0 if math.isnan(v) else v for v in (tw["linear_x"], tw["linear_y"], tw["linear_z"]))
        vel.twist.covariance = tw["covariance"]
        self.pub_vel.publish(vel)

        if fix["stamp"] is not None:
            tref = TimeReference()
            tref.header.stamp = self.get_clock().now().to_msg()
            tref.header.frame_id = self.frame_id
            tref.time_ref = msg.header.stamp
            tref.source = "gnss"
            self.pub_time.publish(tref)

        r = rtk_status_fields(acc.pvt, acc.rtk, acc.ntrip_connected)
        rtk = RtkStatus()
        rtk.header = msg.header
        for key, value in r.items():
            if key != "stamp":
                setattr(rtk, key, value)
        self.pub_rtk.publish(rtk)

        if acc.attitude and acc.attitude.get("heading_deg") is not None:
            q = imu_fields(acc.attitude)
            imu = Imu()
            imu.header = msg.header
            imu.orientation.x, imu.orientation.y, imu.orientation.z, imu.orientation.w = q["orientation"]
            imu.orientation_covariance = q["orientation_covariance"]
            imu.angular_velocity_covariance[0] = -1.0
            imu.linear_acceleration_covariance[0] = -1.0
            self.pub_imu.publish(imu)
            self.pub_heading.publish(Float64(data=float(acc.attitude["heading_deg"])))

        for mark in acc.pop_time_marks():
            m = time_mark_fields(mark)
            tm = TimeMark()
            tm.header.stamp = self._stamp(m["stamp"])
            tm.header.frame_id = self.frame_id
            for key in ("channel", "count", "gps_week", "gps_tow", "time_valid", "acc_est_ns"):
                setattr(tm, key, m[key])
            self.pub_mark.publish(tm)

    def _watchdog(self) -> None:
        stale = self.get_parameter("stale_s").value
        if self._last_epoch and time.monotonic() - self._last_epoch > stale:
            msg = NavSatFix()
            msg.header.stamp = self.get_clock().now().to_msg()
            msg.header.frame_id = self.frame_id
            msg.status.status = NavSatStatus.STATUS_NO_FIX
            msg.latitude = msg.longitude = msg.altitude = float("nan")
            self.pub_fix.publish(msg)

    # ------------------------------------------------------------- websocket thread
    def _ws_thread(self) -> None:
        asyncio.run(self._ws_main())

    async def _ws_main(self) -> None:
        import websockets

        url = self.get_parameter("ws_url").value
        token = self.get_parameter("token").value
        if token:
            url += ("&" if "?" in url else "?") + f"token={token}"
        if "topics=" not in url:
            url += ("&" if "?" in url else "?") + "topics=pvt,rtk"
        reconnect = float(self.get_parameter("reconnect_s").value)
        while not self._stop.is_set():
            try:
                async with websockets.connect(url, max_size=4 * 1024 * 1024) as ws:
                    self.get_logger().info(f"connected to {url}")
                    async for raw in ws:
                        msg: dict[str, Any] = json.loads(raw)
                        with self._lock:
                            if self.acc.ingest(msg):
                                self._last_epoch = time.monotonic()
                                self._publish_epoch()
            except Exception as exc:  # network errors: keep retrying
                self.get_logger().warning(f"websocket disconnected: {exc}; retrying in {reconnect:.0f}s")
                await asyncio.sleep(reconnect)

    # ------------------------------------------------------------- NMEA thread
    def _nmea_thread(self) -> None:
        host, _, port = self.get_parameter("nmea_tcp").value.rpartition(":")
        while not self._stop.is_set():
            try:
                with socket.create_connection((host or "127.0.0.1", int(port)), timeout=10) as sock, sock.makefile("rb") as fh:
                    self.get_logger().info(f"reading NMEA from {host}:{port}")
                    for line in fh:
                        text = line.decode("ascii", "replace").strip()
                        if not text.startswith("$"):
                            continue
                        s = Sentence()
                        s.header.stamp = self.get_clock().now().to_msg()
                        s.header.frame_id = self.frame_id
                        s.sentence = text
                        self.pub_nmea.publish(s)
            except OSError as exc:
                self.get_logger().warning(f"NMEA TCP disconnected: {exc}")
                time.sleep(float(self.get_parameter("reconnect_s").value))

    def destroy_node(self) -> bool:
        self._stop.set()
        return super().destroy_node()


def main(args: list[str] | None = None) -> None:
    rclpy.init(args=args)
    node = MtrtkBridge()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()
```
`RtkStatus` float fields are `float32`/`float64`; assigning Python floats (including NaN) works. Integer fields need `int` — `rtk_status_fields` already returns ints.

def generate_launch_description() -> LaunchDescription:

- [ ] **Step 5: Write `docs/ros2.md`**

```markdown
# ROS 2 bridge

`mtrtk_bridge` publishes the rover state on ROS 2 topics. It talks to the daemon's WebSocket, so the core stays ROS-free and the bridge can run on another machine on the tailnet.

## Run with Docker
```bash
ROS_DISTRO=humble docker compose --profile ros2 up -d       # or jazzy
ros2 topic echo /mtrtk/fix                                    # from any node in the same ROS_DOMAIN_ID (host network)
```
## Run natively (colcon)
```bash
cd ros2 && colcon build && source install/setup.bash
ros2 launch mtrtk_bridge bridge.launch.py ws_url:=ws://<rover-ip>:8080/ws
```
## Topics
| Topic | Type | Notes |
|---|---|---|
| `/mtrtk/fix` | `sensor_msgs/NavSatFix` | status −1/0/1/2 = none/GNSS/DGNSS/RTK; diagonal covariance from hAcc, vAcc |
| `/mtrtk/vel` | `geometry_msgs/TwistWithCovarianceStamped` | ENU velocity |
| `/mtrtk/time_reference` | `sensor_msgs/TimeReference` | receiver UTC |
| `/mtrtk/rtk_status` | `mtrtk_msgs/RtkStatus` | carrier solution, correction age, baseline, RTCM counters |
| `/mtrtk/time_mark` | `mtrtk_msgs/TimeMark` | EXTINT pulses (camera triggers) |
| `/mtrtk/imu`, `/mtrtk/heading` | `sensor_msgs/Imu`, `std_msgs/Float64` | only with an INS driver |
| `/mtrtk/nmea` | `nmea_msgs/Sentence` | when `nmea_tcp` is set |

Parameters: `ws_url`, `token`, `frame_id`, `namespace`, `nmea_tcp`, `reconnect_s`, `stale_s` (see `config/bridge.yaml`). With `robot_localization`, feed `/mtrtk/fix` to `navsat_transform_node` and `/mtrtk/imu` (heading) when available.
```
