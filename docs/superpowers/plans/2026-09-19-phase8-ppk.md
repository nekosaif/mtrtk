# mtrtk Phase 8: PPK Post-Processing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Post-process a rover's raw log against the base's raw log (or RINEX) with RTKLIB `rnx2rtkp` to get a centimetre-level kinematic track after the fact — from the CLI, the API and a PPK page — including camera time marks interpolated onto the track for photogrammetry geotagging, with a zero-baseline self-test in CI.

**Architecture:** `ppk/rtkconf.py` renders the `rnx2rtkp` options file for the F9P (kinematic, combined, L1+L2, GPS+GLO+GAL+BDS, fix-and-hold; demo5-only keys included only when the installed binary knows them). `ppk/pos.py` parses RTKLIB `.pos` output into records, computes a summary and writes track CSV/GeoJSON/KML. `ppk/events.py` pulls TIM-TM2 rising edges out of the rover UBX and interpolates positions for each pulse. `ppk/pipeline.py` resolves inputs (rover: session / window / uploaded file; base: local raw logs, remote base over Tailscale via `GET /api/export/rinex`, or uploaded UBX/RINEX), converts both with the Phase 5 convbin wrapper, runs `rnx2rtkp`, parses and writes outputs, and runs as a Phase 3 job (`kind="ppk"`). The API adds `/api/ppk/*`, the UI a PPK page (form, jobs, track map coloured by solution quality, stats, event table, downloads).

**Tech Stack:** RTKLIB demo5 `rnx2rtkp` + `convbin` (Docker image; stock 2.4.3 works locally with fewer options), Python asyncio subprocess, pydantic, FastAPI multipart, React + MapLibre (track layer).

**Spec:** `docs/superpowers/specs/2026-09-18-mtrtk-design.md` — *ppk*, *rnx2rtkp conf (demo5) additions*, *Phase 8*, open item 3. Prerequisites: Phases 1–6 (fixtures, convbin wrapper, jobs, export endpoint, sessions, time marks). Verified during planning: the stock 2.4.3 `rnx2rtkp` binary does not contain `pos2-arfilter`, `pos2-arthresmin`, `pos2-varholdamb`, `pos2-minfixsats` (demo5-only) but does know `pos1-posmode`, `out-solformat`, `ant2-postype`; the renderer therefore probes the binary.

## Global Constraints

- Baseline options (always): `pos1-posmode=kinematic`, `pos1-frequency=l1+l2`, `pos1-soltype=combined`, `pos1-elmask=15`, `pos1-snrmask_r=off`, `pos1-dynamics=on`, `pos1-tidecorr=off`, `pos1-ionoopt=brdc`, `pos1-tropopt=saas`, `pos1-sateph=brdc`, `pos1-navsys=45` (GPS+GLO+GAL+BDS; 61 with QZSS), `pos2-armode=fix-and-hold`, `pos2-gloarmode=on`, `pos2-bdsarmode=on`, `pos2-arthres=3`, `pos2-arlockcnt=5`, `pos2-arelmask=15`, `pos2-arminfix=10`, `pos2-elmaskhold=15`, `pos2-aroutcnt=20`, `pos2-maxage=30`, `pos2-rejionno=1`, `pos2-rejgdop=30`, `pos2-slipthres=0.05`, `out-solformat=llh`, `out-outhead=on`, `out-outopt=on`, `out-timesys=gpst`, `out-timeform=hms`, `out-timendec=3`, `out-degform=deg`, `out-height=ellipsoidal`, `out-outstat=residual`, `out-solstatic=all`, `stats-errphase=0.003`, `stats-errphaseel=0.003`, `stats-prnaccelh=3`, `stats-prnaccelv=1`, `ant2-postype=xyz`, `ant2-pos1/2/3=<base ECEF>`, `ant2-maxaveep=1`, `misc-timeinterp=off`. Demo5-only additions when supported: `pos2-arfilter=on`, `pos2-arthresmin=3`, `pos2-arthresmax=3`, `pos2-arthres1=0.1`, `pos2-varholdamb=0.1`, `pos2-gainholdamb=0.01`, `pos2-minfixsats=4`, `pos2-minholdsats=5`, `pos2-mindropsats=10`, `stats-eratio1=300`, `stats-eratio2=300`.
- `gloarmode=on` is valid because both ends are F9P; when the base RINEX header's receiver type is not a u-blox, the pipeline switches it to `autocal` and adds a warning.
- Base coordinates (ECEF) come from, in order: an explicit site name, explicit XYZ, the base RINEX `APPROX POSITION XYZ` header, else the pipeline fails with "base position unknown".
- Both RINEX conversions use the Phase 5 `run_convbin` with `-TADJ=1.0`; rover at native rate, base at native rate (never decimated for PPK).
- `.pos` records: `time (GPST)`, `lat`, `lon`, `height`, `q` (1 fixed, 2 float, 3 sbas, 4 dgps, 5 single, 6 ppp), `ns`, `sdn`, `sde`, `sdu`, `sdne`, `sdeu`, `sdun`, `age`, `ratio`. Summary: epochs, fixed %, float %, single %, mean σ (fixed epochs), gaps > 2 s, duration.
- Events: TIM-TM2 rising edges with `time` valid → GPST (`week`, `tow`) → linear interpolation between the neighbouring epochs when both are within `max_gap_s` (default 2.0); output `events.csv` (`n, gps_week, gps_tow, utc, lat, lon, height_m, q, sdn, sde, sdu, interp_gap_s`) and GeoJSON.
- Outputs per job (`DATA_DIR/jobs/<id>/`): `rover.rnx`, `rover_MN.rnx`, `base.rnx`, `base_MN.rnx` (or the given base files), `ppk.conf`, `track.pos`, `track.pos.stat`, `track.csv`, `track.geojson`, `track.kml`, `events.csv` + `events.geojson` (when marks exist), `summary.json`, `rnx2rtkp.log`.
- Zero-baseline self-test: rover = base = the same raw fixture; CI asserts `epochs > 0` and `q ∈ {1, 2}` for every epoch (identical observations make ambiguity resolution trivial).

def rnx2rtkp_available(binary: str = "rnx2rtkp") -> bool:
    return shutil.which(binary) is not None or Path(binary).is_file()


@lru_cache(maxsize=8)
def _binary_bytes(binary: str) -> bytes:
    path = shutil.which(binary) or binary
    try:
        return Path(path).read_bytes()
    except OSError:
        return b""


def rnx2rtkp_supports(key: str, binary: str = "rnx2rtkp") -> bool:
    """RTKLIB keeps option names as C strings in the executable; demo5 adds keys stock 2.4.3 lacks."""
    return key.encode() in _binary_bytes(binary)


def render_conf(base_xyz: tuple[float, float, float], *, overrides: dict[str, str] | None = None, glonass_ar: str = "on", include_qzss: bool = False, binary: str = "rnx2rtkp") -> str:
    options = dict(BASE_OPTIONS)
    options["pos2-gloarmode"] = glonass_ar
    if include_qzss:
        options["pos1-navsys"] = "61"
    if rnx2rtkp_supports("pos2-arfilter", binary):
        options.update(DEMO5_OPTIONS)
    options["ant2-pos1"], options["ant2-pos2"], options["ant2-pos3"] = (f"{v:.4f}" for v in base_xyz)
    if overrides:
        options.update(overrides)
    lines = ["# rnx2rtkp options generated by mtrtk (ZED-F9P kinematic PPK)"]
    lines += [f"{k:<20}={v}" for k, v in options.items()]
    return "\n".join(lines) + "\n"


def parse_conf(text: str) -> dict[str, str]:
    out: dict[str, str] = {}
    for raw in text.splitlines():
        line = raw.split("#", 1)[0].strip()
        if not line or "=" not in line:
            continue
        key, value = line.split("=", 1)
        out[key.strip()] = value.strip()
    return out
```

```python
"""RTKLIB .pos solution files: parse, summarize, and write track CSV/GeoJSON/KML."""

from __future__ import annotations

import csv
import io
from dataclasses import dataclass, field
from datetime import UTC, datetime
from typing import Any

Q_NAMES = {1: "fixed", 2: "float", 3: "sbas", 4: "dgps", 5: "single", 6: "ppp"}
Q_COLORS_KML = {1: "ff00c30c", 2: "ff19b2fa", 3: "ff5a83ec", 4: "ff5a83ec", 5: "ff3b3bd0", 6: "ffe9b085"}  # aabbggrr


@dataclass(frozen=True)
class PosRecord:
    time: datetime  # GPST labelled as UTC tzinfo for arithmetic; the CSV header says GPST
    lat: float
    lon: float
    height: float
    q: int
    ns: int
    sdn: float
    sde: float
    sdu: float
    sdne: float
    sdeu: float
    sdun: float
    age: float
    ratio: float

    @property
    def quality(self) -> str:
        return Q_NAMES.get(self.q, str(self.q))


def parse_pos(text: str) -> list[PosRecord]:
    out: list[PosRecord] = []
    for raw in text.splitlines():
        line = raw.strip()
        if not line or line.startswith("%"):
            continue
        parts = line.split()
        if len(parts) < 15:
            continue
        try:
            t = datetime.strptime(f"{parts[0]} {parts[1]}", "%Y/%m/%d %H:%M:%S.%f").replace(tzinfo=UTC)
            nums = [float(v) for v in parts[2:15]]
        except ValueError:
            continue
        out.append(PosRecord(t, nums[0], nums[1], nums[2], int(nums[3]), int(nums[4]), *nums[5:11], nums[11], nums[12]))
    return out


@dataclass
class PpkSummary:
    epochs: int = 0
    duration_s: float = 0.0
    interval_s: float | None = None
    fixed_pct: float = 0.0
    float_pct: float = 0.0
    single_pct: float = 0.0
    mean_sd_fixed: dict[str, float] | None = None
    gaps: list[tuple[datetime, datetime, float]] = field(default_factory=list)
    first_time: datetime | None = None
    last_time: datetime | None = None

    def to_json(self) -> dict[str, Any]:
        return {**{k: v for k, v in self.__dict__.items() if k not in ("gaps", "first_time", "last_time")}, "gaps": [[a.isoformat(), b.isoformat(), s] for a, b, s in self.gaps], "first_time": self.first_time.isoformat() if self.first_time else None, "last_time": self.last_time.isoformat() if self.last_time else None}


def summarize(records: list[PosRecord], gap_s: float = 2.0) -> PpkSummary:
    s = PpkSummary(epochs=len(records))
    if not records:
        return s
    s.first_time, s.last_time = records[0].time, records[-1].time
    s.duration_s = (s.last_time - s.first_time).total_seconds()
    deltas = sorted((b.time - a.time).total_seconds() for a, b in zip(records, records[1:], strict=False))
    if deltas:
        s.interval_s = deltas[len(deltas) // 2]
    n = len(records)
    s.fixed_pct = round(100 * sum(r.q == 1 for r in records) / n, 2)
    s.float_pct = round(100 * sum(r.q == 2 for r in records) / n, 2)
    s.single_pct = round(100 * sum(r.q == 5 for r in records) / n, 2)
    fixed = [r for r in records if r.q == 1]
    if fixed:

```python
"""Camera/event time marks (UBX TIM-TM2) interpolated onto a PPK track."""

from __future__ import annotations

import bisect
import csv
import io
from dataclasses import dataclass
from datetime import UTC, datetime, timedelta
from pathlib import Path
from typing import Any

from mtrtk.core.frames import Framer, Proto
from mtrtk.ppk.pos import PosRecord

GPS_EPOCH = datetime(1980, 1, 6, tzinfo=UTC)
WEEK_S = 604800


@dataclass(frozen=True)
class RawTimeMark:
    count: int
    week: int
    tow_s: float
    acc_est_ns: int


@dataclass(frozen=True)
class EventFix:
    n: int
    count: int
    week: int
    tow_s: float
    time: datetime
    lat: float | None
    lon: float | None
    height: float | None
    q: int | None
    sdn: float | None
    sde: float | None
    sdu: float | None
    gap_s: float | None
    status: str


def gpst_datetime(week: int, tow_s: float) -> datetime:
    return GPS_EPOCH + timedelta(seconds=week * WEEK_S + tow_s)


def extract_time_marks(ubx_path: Path) -> list[RawTimeMark]:
    marks: dict[int, RawTimeMark] = {}
    for frame in Framer().feed(Path(ubx_path).read_bytes()):
        if frame.proto is not Proto.UBX or frame.identity != "TIM-TM2":
            continue
        m = frame.parsed()
        if not (m.newRisingEdge and m.time):
            continue
        marks.setdefault(int(m.count), RawTimeMark(int(m.count), int(m.wnR), m.towMsR / 1000 + m.towSubMsR / 1e9, int(m.accEst)))
    return sorted(marks.values(), key=lambda mk: (mk.week, mk.tow_s))


def _lerp(a: float, b: float, f: float) -> float:
    return a + (b - a) * f


def interpolate_events(marks: list[RawTimeMark], records: list[PosRecord], max_gap_s: float = 2.0) -> list[EventFix]:
    times = [r.time for r in records]
    out: list[EventFix] = []
    for n, mk in enumerate(marks, start=1):
        t = gpst_datetime(mk.week, mk.tow_s)
        idx = bisect.bisect_left(times, t)
        if idx == 0 or idx >= len(records):
            out.append(EventFix(n, mk.count, mk.week, mk.tow_s, t, None, None, None, None, None, None, None, None, "no_neighbours"))
            continue
        a, b = records[idx - 1], records[idx]
        gap = (b.time - a.time).total_seconds()
        if gap > max_gap_s:
            out.append(EventFix(n, mk.count, mk.week, mk.tow_s, t, None, None, None, None, None, None, None, gap, "gap_too_large"))
            continue
        f = (t - a.time).total_seconds() / gap if gap > 0 else 0.0
        out.append(EventFix(n, mk.count, mk.week, mk.tow_s, t, _lerp(a.lat, b.lat, f), _lerp(a.lon, b.lon, f), _lerp(a.height, b.height, f), max(a.q, b.q), max(a.sdn, b.sdn), max(a.sde, b.sde), max(a.sdu, b.sdu), gap, "ok"))
    return out


def events_csv(events: list[EventFix]) -> str:
    buf = io.StringIO()
    w = csv.writer(buf, lineterminator="\n")
    w.writerow(["n", "count", "gps_week", "gps_tow_s", "time_gpst", "lat", "lon", "height_m", "q", "sdn_m", "sde_m", "sdu_m", "interp_gap_s", "status"])
    for e in events:
        w.writerow([e.n, e.count, e.week, f"{e.tow_s:.6f}", e.time.isoformat(), "" if e.lat is None else f"{e.lat:.9f}", "" if e.lon is None else f"{e.lon:.9f}", "" if e.height is None else f"{e.height:.4f}", "" if e.q is None else e.q, "" if e.sdn is None else f"{e.sdn:.4f}", "" if e.sde is None else f"{e.sde:.4f}", "" if e.sdu is None else f"{e.sdu:.4f}", "" if e.gap_s is None else f"{e.gap_s:.3f}", e.status])
    return buf.getvalue()


def events_geojson(events: list[EventFix]) -> dict[str, Any]:
    return {"type": "FeatureCollection", "features": [
        {"type": "Feature", "geometry": {"type": "Point", "coordinates": [e.lon, e.lat, e.height]}, "properties": {"n": e.n, "count": e.count, "time": e.time.isoformat(), "q": e.q, "sdn": e.sdn, "sde": e.sde, "sdu": e.sdu, "status": e.status}}
        for e in events if e.lat is not None
    ]}

```python
"""Read the few RINEX observation header fields PPK needs."""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path


@dataclass(frozen=True)
class RinexHeaderInfo:
    version: str
    marker: str
    receiver_type: str
    antenna_type: str
    approx_xyz: tuple[float, float, float] | None
    interval: float | None


def read_header(path: Path) -> RinexHeaderInfo:
    version = marker = receiver = antenna = ""
    xyz: tuple[float, float, float] | None = None
    interval: float | None = None
    with Path(path).open(encoding="utf-8", errors="replace") as fh:
        for line in fh:
            label = line[60:].strip()
            body = line[:60]
            if label == "RINEX VERSION / TYPE":
                version = body[:9].strip()
            elif label == "MARKER NAME":
                marker = body.strip()
            elif label == "REC # / TYPE / VERS":
                receiver = body[20:40].strip()
            elif label == "ANT # / TYPE":
                antenna = body[20:40].strip()
            elif label == "APPROX POSITION XYZ":
                try:
                    x, y, z = (float(body[i : i + 14]) for i in (0, 14, 28))
                    xyz = (x, y, z) if any((x, y, z)) else None
                except ValueError:
                    xyz = None
            elif label == "INTERVAL":
                try:
                    interval = float(body.strip())
                except ValueError:
                    interval = None
            elif label == "END OF HEADER":
                break
    return RinexHeaderInfo(version, marker, receiver, antenna, xyz, interval)
```

from __future__ import annotations

import asyncio
import json
import logging
import shutil
from collections.abc import Awaitable, Callable
from dataclasses import dataclass, field
from datetime import UTC, datetime
from pathlib import Path

import httpx
from pydantic import BaseModel, model_validator

from mtrtk.jobs import JobContext, JobFn
from mtrtk.ppk.events import events_csv, events_geojson, extract_time_marks, interpolate_events
from mtrtk.ppk.pos import parse_pos, summarize, track_csv, track_geojson, track_kml

from mtrtk.rover.sessions import SessionsRepo

log = logging.getLogger(__name__)
Progress = Callable[[float, str | None], Awaitable[None]]


class PpkError(RuntimeError):
    pass


class RoverSource(BaseModel):
    kind: Literal["session", "window", "upload"]
    session_id: int | None = None
    start: datetime | None = None
    end: datetime | None = None
    path: Path | None = None  # uploaded .ubx (or RINEX obs)

    @model_validator(mode="after")
    def _check(self) -> RoverSource:
        if self.kind == "session" and self.session_id is None:
            raise ValueError("session_id required")
        if self.kind == "window" and (self.start is None or self.end is None):
            raise ValueError("start and end required")
        if self.kind == "upload" and self.path is None:
            raise ValueError("path required")
        return self


class BaseSource(BaseModel):
    kind: Literal["local", "remote", "upload"]
    url: str | None = None
    path_ubx: Path | None = None
    path_obs: Path | None = None
    path_nav: Path | None = None

    @model_validator(mode="after")
    def _check(self) -> BaseSource:
        if self.kind == "remote" and not self.url:
            raise ValueError("url required for a remote base")
        if self.kind == "upload" and not (self.path_ubx or self.path_obs):
            raise ValueError("path_ubx or path_obs required for an uploaded base")
        return self


class PpkRequest(BaseModel):
    rover: RoverSource
    base: BaseSource
    base_site: str | None = None
    base_xyz: tuple[float, float, float] | None = None
    events: bool = True
    include_qzss: bool = False
    conf_overrides: dict[str, str] = {}
    max_gap_s: float = 2.0


@dataclass
class PpkContext:
    root: Path
    station_id: str
    country: str
    header: RinexHeader
    db: Database
    http: Callable[[], httpx.AsyncClient] = field(default=lambda: httpx.AsyncClient(timeout=120.0))
    rnx2rtkp: str = "rnx2rtkp"


async def _resolve_window(req: PpkRequest, ctx: PpkContext) -> tuple[datetime, datetime]:
    r = req.rover
    if r.kind == "window":
        assert r.start and r.end
        return r.start, r.end
    if r.kind == "session":
        session = next((s for s in await SessionsRepo(ctx.db).list(limit=1000) if s.id == r.session_id), None)
        if session is None:
            raise PpkError(f"session {r.session_id} not found")
        return session.start_utc, session.end_utc or datetime.now(UTC)
    raise PpkError("uploaded rover files have no window; base must be uploaded or given as RINEX")


async def _rover_rinex(req: PpkRequest, ctx: PpkContext, out: Path, window: tuple[datetime, datetime] | None) -> tuple[Path, Path, Path | None]:
    """Returns (obs, nav, ubx_path_for_events)."""
    opts = ConvbinOptions(header=ctx.header)
    if req.rover.kind == "upload":
        src = req.rover.path
        assert src is not None
        if src.suffix.lower() == ".ubx":
            res = await run_convbin(src, out / "rover.rnx", out / "rover_MN.rnx", opts)
            return res.obs_path, res.nav_path, src
        shutil.copy(src, out / "rover.rnx")
        return out / "rover.rnx", out / "rover_MN.rnx", None
    assert window is not None
    try:
        spliced = splice_window(ctx.root, window[0], window[1], out / "rover.ubx", lead_hours=0)
    except NoDataError as exc:
        raise PpkError(f"rover: {exc}") from exc
    res = await run_convbin(spliced.path, out / "rover.rnx", out / "rover_MN.rnx", ConvbinOptions(header=ctx.header, start=window[0], end=window[1]))
    return res.obs_path, res.nav_path, spliced.path


async def _base_rinex(req: PpkRequest, ctx: PpkContext, out: Path, window: tuple[datetime, datetime] | None) -> tuple[Path, Path, dict[str, Any]]:
    b = req.base
    info: dict[str, Any] = {"kind": b.kind}
    opts = ConvbinOptions(header=RinexHeader(marker_name="BASE", observer=ctx.header.observer, agency=ctx.header.agency, receiver_version="unknown"))
    if b.kind == "upload":
        if b.path_ubx:
            res = await run_convbin(b.path_ubx, out / "base.rnx", out / "base_MN.rnx", opts)
            return res.obs_path, res.nav_path, info
        assert b.path_obs
        shutil.copy(b.path_obs, out / "base.rnx")
        if b.path_nav:
            shutil.copy(b.path_nav, out / "base_MN.rnx")
        else:
            (out / "base_MN.rnx").write_text("")
        return out / "base.rnx", out / "base_MN.rnx", info
    if window is None:
        raise PpkError("a local or remote base needs a rover window (session or start/end)")
    start, end = window
    if b.kind == "local":
        try:
            spliced = splice_window(ctx.root, start, end, out / "base.ubx")
        except NoDataError as exc:
            raise PpkError(f"base: {exc}") from exc
        res = await run_convbin(spliced.path, out / "base.rnx", out / "base_MN.rnx", ConvbinOptions(header=opts.header, start=start, end=end))
        return res.obs_path, res.nav_path, info
    assert b.url
    url = b.url.rstrip("/")
    async with ctx.http() as client:
        resp = await client.get(f"{url}/api/logs/window", params={"from": start.isoformat(), "to": end.isoformat()})
        if resp.status_code == 404:
            raise PpkError(f"remote base has no raw logs for {start.isoformat()} – {end.isoformat()}")
        resp.raise_for_status()
        (out / "base.ubx").write_bytes(resp.content)
        info["remote_bytes"] = len(resp.content)
        if req.base_site is None and req.base_xyz is None:
            sites = await client.get(f"{url}/api/base/sites")
            if sites.status_code == 200:
                active = next((s for s in sites.json() if s.get("active")), None)
                if active:
                    info["remote_site"] = active
    res = await run_convbin(out / "base.ubx", out / "base.rnx", out / "base_MN.rnx", ConvbinOptions(header=opts.header, start=start, end=end))
    return res.obs_path, res.nav_path, info


async def _base_xyz(req: PpkRequest, ctx: PpkContext, base_obs: Path, base_info: dict[str, Any]) -> tuple[tuple[float, float, float], str]:
    if req.base_site:
        site = await SitesRepo(ctx.db).get(req.base_site)
        if site is None:
            raise PpkError(f"site {req.base_site!r} not found")
        return (site.x, site.y, site.z), f"site:{req.base_site}"
    if req.base_xyz:
        return req.base_xyz, "request"
    remote = base_info.get("remote_site")
    if remote:
        return (remote["x"], remote["y"], remote["z"]), f"remote-site:{remote['name']}"
    hdr = read_header(base_obs)
    if hdr.approx_xyz:
        return hdr.approx_xyz, "rinex-header"
    raise PpkError("base position unknown: give a site name, ECEF coordinates, or a base RINEX with APPROX POSITION XYZ")


async def _run_rnx2rtkp(ctx: PpkContext, out: Path, conf: Path, rover_obs: Path, base_obs: Path, navs: list[Path]) -> Path:
    if not rnx2rtkp_available(ctx.rnx2rtkp):
        raise PpkError("rnx2rtkp not found; install RTKLIB or use the Docker image")
    pos = out / "track.pos"
    cmd = [ctx.rnx2rtkp, "-k", str(conf), "-o", str(pos), str(rover_obs), str(base_obs), *[str(n) for n in navs if n.exists() and n.stat().st_size > 0]]
    proc = await asyncio.create_subprocess_exec(*cmd, stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.STDOUT)
    output, _ = await proc.communicate()
    (out / "rnx2rtkp.log").write_bytes(b" ".join(c.encode() for c in cmd) + b"\n" + output)
    if proc.returncode != 0 or not pos.exists():
        raise PpkError(f"rnx2rtkp failed (exit {proc.returncode}): {output.decode(errors='replace')[-400:]}")
    return pos


async def run_ppk(req: PpkRequest, ctx: PpkContext, out: Path, progress: Progress | None = None) -> dict[str, Any]:
    async def report(p: float, msg: str) -> None:
        if progress:
            await progress(p, msg)

    out.mkdir(parents=True, exist_ok=True)
    warnings: list[str] = []
    window = None if req.rover.kind == "upload" else await _resolve_window(req, ctx)
    await report(0.05, "converting rover observations")
    try:
        rover_obs, rover_nav, rover_ubx = await _rover_rinex(req, ctx, out, window)
        await report(0.3, "preparing base observations")
        base_obs, base_nav, base_info = await _base_rinex(req, ctx, out, window)
    except ConvbinError as exc:
        raise PpkError(str(exc)) from exc
    xyz, xyz_source = await _base_xyz(req, ctx, base_obs, base_info)
    base_hdr = read_header(base_obs)
    glonass_ar = "on"
    if base_hdr.receiver_type and "u-blox" not in base_hdr.receiver_type.lower() and base_hdr.receiver_type.lower() not in ("", "unknown"):
        glonass_ar = "autocal"
        warnings.append(f"base receiver is {base_hdr.receiver_type!r}; GLONASS ambiguity resolution set to autocal")
    conf_path = out / "ppk.conf"
    conf_path.write_text(render_conf(xyz, overrides=req.conf_overrides, glonass_ar=glonass_ar, include_qzss=req.include_qzss, binary=ctx.rnx2rtkp))
    await report(0.45, "running rnx2rtkp")
    pos_path = await _run_rnx2rtkp(ctx, out, conf_path, rover_obs, base_obs, [rover_nav, base_nav])
    records = parse_pos(pos_path.read_text(errors="replace"))
    if not records:
        raise PpkError("rnx2rtkp produced no solution epochs; check rnx2rtkp.log (overlapping time spans? matching signals?)")
    await report(0.8, "writing track")
    summary = summarize(records, gap_s=req.max_gap_s)
    (out / "track.csv").write_text(track_csv(records))
    (out / "track.geojson").write_text(json.dumps(track_geojson(records)))
    (out / "track.kml").write_text(track_kml(records))
    events_summary: dict[str, Any] = {"total": 0, "ok": 0, "gap_too_large": 0, "no_neighbours": 0}
    if req.events and rover_ubx is not None:
        marks = extract_time_marks(rover_ubx)
        if marks:
            events = interpolate_events(marks, records, req.max_gap_s)
            (out / "events.csv").write_text(events_csv(events))
            (out / "events.geojson").write_text(json.dumps(events_geojson(events)))
            events_summary = {"total": len(events), **{k: sum(e.status == k for e in events) for k in ("ok", "gap_too_large", "no_neighbours")}}
    if summary.fixed_pct < 50:
        warnings.append(f"only {summary.fixed_pct:.0f}% of epochs are RTK fixed; check baseline length, sky view and that base/rover windows overlap")
    for scratch in ("rover.ubx", "base.ubx"):
        (out / scratch).unlink(missing_ok=True)
    files = [{"name": p.name, "bytes": p.stat().st_size} for p in sorted(out.iterdir()) if p.is_file()]
    result = {
        "summary": summary.to_json(), "events": events_summary, "warnings": warnings,
        "inputs": {"rover": req.rover.model_dump(mode="json"), "base": {**req.base.model_dump(mode="json"), **{k: v for k, v in base_info.items() if k != "remote_site"}}, "base_xyz": list(xyz), "base_xyz_source": xyz_source, "glonass_ar": glonass_ar, "window": [window[0].isoformat(), window[1].isoformat()] if window else None},
        "files": files,
    }
    (out / "summary.json").write_text(json.dumps(result, indent=2, default=str))
    await report(1.0, "done")
    return result


def make_ppk_job(req: PpkRequest, ctx: PpkContext) -> JobFn:
    async def job(jctx: JobContext) -> dict[str, Any]:
        return await run_ppk(req, ctx, jctx.dir, progress=jctx.progress)

    return job
```
Note: `rover_ubx` for a windowed rover is the spliced file, which is deleted at the end **after** events are extracted (order above is correct). `splice_window(..., lead_hours=0)` for the rover: the rover nav file comes from its own stream; the base lead hour supplies ephemerides too.

def ppk(rover_file, session_id, start, end, base_file, base_nav, base_url, base_logs, site, base_xyz, no_events, qzss, overrides, out_dir) -> None:  # type: ignore[no-untyped-def]
    """Post-process rover raw data against a base (PPK) with RTKLIB."""
    from datetime import datetime

    from pydantic import ValidationError

    from mtrtk.ppk.pipeline import BaseSource, PpkContext, PpkError, PpkRequest, RoverSource, run_ppk
    from mtrtk.rinex.export import header_from_settings
    from mtrtk.store.db import Database

    settings = _load_settings(ntrip_password="")
    try:
        if rover_file:
            rover = RoverSource(kind="upload", path=rover_file)
        elif session_id is not None:
            rover = RoverSource(kind="session", session_id=session_id)
        elif start and end:
            rover = RoverSource(kind="window", start=datetime.fromisoformat(start.replace("Z", "+00:00")), end=datetime.fromisoformat(end.replace("Z", "+00:00")))
        else:
            raise click.UsageError("give a rover source: --rover FILE, --session ID, or --from/--to")
        if base_file:

        elif base_url:
            base = BaseSource(kind="remote", url=base_url)
        elif base_logs:
            base = BaseSource(kind="local")
        else:
            raise click.UsageError("give a base source: --base FILE, --base-url URL, or --base-logs")
        conf = dict(item.split("=", 1) for item in overrides)
        request = PpkRequest(rover=rover, base=base, base_site=site, base_xyz=tuple(base_xyz) if base_xyz else None, events=not no_events, include_qzss=qzss, conf_overrides=conf)
    except (ValidationError, ValueError) as exc:
        raise click.ClickException(str(exc)) from exc

    async def go() -> None:
        db = Database(settings.data_dir / "mtrtk.db")
        await db.open()
        try:
            ctx = PpkContext(root=settings.data_dir, station_id=settings.station_id, country=settings.country, header=header_from_settings(settings, None, None), db=db)

            async def progress(p: float, msg: str | None) -> None:
                click.echo(f"[{p * 100:3.0f}%] {msg or ''}")

                result = await run_ppk(request, ctx, out_dir, progress=progress)
            except PpkError as exc:
                raise click.ClickException(str(exc)) from exc
        finally:
            await db.close()
        s = result["summary"]
        click.echo(f"{s['epochs']} epochs · fixed {s['fixed_pct']:.1f}% · float {s['float_pct']:.1f}% · single {s['single_pct']:.1f}% · base {result['inputs']['base_xyz_source']}")
        if result["events"]["total"]:
            click.echo(f"events: {result['events']['ok']} of {result['events']['total']} positioned")
        for w in result["warnings"]:
            click.echo(f"warning: {w}")
        click.echo(f"outputs in {out_dir}")

    asyncio.run(go())

```python
"""PPK jobs: uploads, defaults, submission. Results come through /api/jobs."""

from __future__ import annotations

import uuid
from datetime import datetime
from pathlib import Path
from typing import Any, Literal
from urllib.parse import urlparse

from fastapi import APIRouter, File, Form, HTTPException, Request, UploadFile
from pydantic import BaseModel, ValidationError

from mtrtk.ppk.pipeline import BaseSource, PpkContext, PpkRequest, RoverSource, make_ppk_job
from mtrtk.ppk.rtkconf import BASE_OPTIONS, DEMO5_OPTIONS, rnx2rtkp_available, rnx2rtkp_supports
from mtrtk.rinex.convbin import convbin_available
from mtrtk.rinex.export import header_from_settings
from mtrtk.store.repos import SitesRepo

router = APIRouter(prefix="/api/ppk", tags=["ppk"])
MAX_UPLOAD = 2 * 1024 ** 3


class RoverBody(BaseModel):
    kind: Literal["session", "window", "upload"]
    session_id: int | None = None
    start: datetime | None = None
    end: datetime | None = None
    upload_id: str | None = None


class BaseBody(BaseModel):
    kind: Literal["local", "remote", "upload"]
    url: str | None = None
    upload_id: str | None = None
    nav_upload_id: str | None = None


class PpkSubmit(BaseModel):
    rover: RoverBody
    base: BaseBody
    base_site: str | None = None
    base_xyz: tuple[float, float, float] | None = None
    events: bool = True
    include_qzss: bool = False
    conf_overrides: dict[str, str] = {}


def _uploads(request: Request) -> Path:
    return request.app.state.ctx.settings.data_dir / "uploads"


def _upload_path(request: Request, upload_id: str | None) -> Path | None:
    if not upload_id:
        return None
    folder = _uploads(request) / upload_id
    if not upload_id.isalnum() or not folder.is_dir():
        raise HTTPException(404, f"upload {upload_id} not found")
    files = [p for p in folder.iterdir() if p.is_file()]
    if not files:
        raise HTTPException(404, f"upload {upload_id} is empty")
    return files[0]


def _detect(head: bytes) -> str | None:
    if head[:2] == b"\xb5\x62" or b"\xb5\x62" in head[:4096]:
        return "ubx"
    if b"RINEX VERSION / TYPE" in head[:200]:
        return "rinex"
    return None


@router.get("/defaults")
async def defaults(request: Request) -> dict[str, Any]:
    s = request.app.state.ctx.settings
    demo5 = rnx2rtkp_supports("pos2-arfilter")
    conf = dict(BASE_OPTIONS)
    if demo5:
        conf.update(DEMO5_OPTIONS)
    base_url = None
    if s.ntrip_url:
        host = urlparse(s.ntrip_url if "://" in s.ntrip_url else f"ntrip://{s.ntrip_url}").hostname
        base_url = f"http://{host}:8080" if host else None
    return {"rnx2rtkp": rnx2rtkp_available(), "convbin": convbin_available(), "demo5": demo5, "conf": conf, "ntrip_base_url": base_url}


@router.post("/upload")
async def upload(request: Request, kind: Literal["rover", "base"] = Form(...), file: UploadFile = File(...)) -> dict[str, Any]:
    upload_id = uuid.uuid4().hex[:12]
    folder = _uploads(request) / upload_id
    folder.mkdir(parents=True, exist_ok=True)
    name = Path(file.filename or f"{kind}.bin").name
    target = folder / name
    size = 0
    head = b""
    with target.open("wb") as fh:
        while chunk := await file.read(1 << 20):
            if not head:
                head = chunk[:4096]
            size += len(chunk)
            if size > MAX_UPLOAD:
                fh.close()
                target.unlink(missing_ok=True)
                raise HTTPException(413, "upload larger than 2 GB")
            fh.write(chunk)
    detected = _detect(head)
    if detected is None:
        target.unlink(missing_ok=True)
        folder.rmdir()
        raise HTTPException(422, "file is neither UBX nor RINEX")
    return {"upload_id": upload_id, "name": name, "bytes": size, "detected": detected, "kind": kind}


@router.post("")
async def submit(body: PpkSubmit, request: Request) -> dict[str, Any]:
    ctx = request.app.state.ctx
    if ctx.jobs is None:
        raise HTTPException(409, "job runner not available")
    rover_path = _upload_path(request, body.rover.upload_id)
    base_path = _upload_path(request, body.base.upload_id)
    nav_path = _upload_path(request, body.base.nav_upload_id)
    try:
        rover = RoverSource(kind=body.rover.kind, session_id=body.rover.session_id, start=body.rover.start, end=body.rover.end, path=rover_path)
        base_kw: dict[str, Any] = {"kind": body.base.kind, "url": body.base.url}
        if base_path is not None:
            base_kw["path_ubx" if base_path.suffix.lower() == ".ubx" else "path_obs"] = base_path
            base_kw["path_nav"] = nav_path
        req = PpkRequest(rover=rover, base=BaseSource(**base_kw), base_site=body.base_site, base_xyz=body.base_xyz, events=body.events, include_qzss=body.include_qzss, conf_overrides=body.conf_overrides)
    except (ValidationError, ValueError) as exc:
        raise HTTPException(422, str(exc)) from exc
    site = await SitesRepo(ctx.db).active()
    pctx = PpkContext(root=ctx.settings.data_dir, station_id=ctx.settings.station_id, country=ctx.settings.country, header=header_from_settings(ctx.settings, ctx.store.state, site), db=ctx.db)
    job = await ctx.jobs.submit("ppk", body.model_dump(mode="json"), make_ppk_job(req, pctx))
    return job.model_dump(mode="json")

# PPK (post-processed kinematic)

Use PPK when the rover had no live corrections (no network, long baseline) or when you want the best possible
track after the fact. Inputs: the rover's raw UBX (always logged) and the base's raw UBX for the same time
range; output: an RTKLIB track with per-epoch quality, plus positions for every camera pulse (TIM-TM2).

## From the UI
PPK page → rover source (a field session, a time window, or an uploaded .ubx) → base source (your base over
Tailscale, an uploaded .ubx/RINEX, or this host's own logs) → base coordinates (the base's active site is used
automatically for a remote base) → Run. Results: track map coloured by quality, quality strip, statistics,
downloads (`track.csv`, `track.geojson`, `track.kml`, `events.csv`, `track.pos`, `rnx2rtkp.log`).

## From the CLI
```bash
mtrtk ppk --session 3 --base-url http://100.100.50.10:8080 --out ./ppk-2026-09-19
mtrtk ppk --rover flight.ubx --base base.ubx --base-xyz -26748.172 5837156.618 2561801.261 --out ./ppk
```

## Geotagging photos
`events.csv` lists each EXTINT pulse with GPS time and the interpolated position (status `ok`, `gap_too_large`,
`no_neighbours`). Match pulse `count` to image order; `sdn/sde/sdu` are the neighbouring epochs' sigmas.

## Reading the result
- `fixed_pct` near 100 with `mean_sd_fixed` of a few millimetres: good.
- Mostly float: long baseline, poor sky, or base/rover windows barely overlapping (check `gaps`).
- "base position unknown": give `--site` or `--base-xyz`, or make sure the base has an active site.
- The Docker image ships RTKLIB demo5 (better ambiguity resolution); a stock RTKLIB 2.4.3 works with fewer options.
